## Continuation Changes

| Area | Fixed behavior | Regression coverage |
| --- | --- | --- |
| Credential origin | Native HTTP and static scenario checks enforce the verified endpoint's origin, including scheme/port; existing verification cannot move a session generation across origins | First verification, re-verification, multi-origin scope and readable-but-stale historical captures |
| Resource binding | Reject repeated query selectors, duplicate JSON keys, ambiguous recursive keys, repeated MIME fields/parameters and global aliases selecting multiple parts | Equal duplicates, encoded query names, quoted/unquoted/folded MIME parameters, JSON Pointer and historical rechecks |
| Actor-only writes | Empty input inventory cannot hide actual query/body data; fixture-free actor writes require a concrete, query-free, body-free HTTP request | Real and deferred business inputs, path placeholders, explicit fixture alternatives and historical weak writes |
| Tool lineage | Capture-time actor/security revision, credentials/classification, input policy, endpoint and actual request-context digests bind metadata proof; original log digests are immutable | Relabeled subjects/roles, credential rotation/classification, another resource/header/baseline, input changes, TTL and missing legacy snapshots |
| Artifact privacy | Plain HTTP MCP content omits bodies/private headers; unescaped traces show only initial recognizable framing and explicit later-packet omission | Body-forged markers, same IDs, fake delimiters, conflicting framing, old credentials and log/run digest tampering |

## Compatibility And Limits

- History is not deleted. Cross-origin, ambiguous-resource or fixture-free
  business-write captures remain byte-inspectable but cannot support current proof.
- Old tool runs without capture-time snapshots remain `lineage:legacy` and
  `usable_for_confirmation:false`. The upgrade does not invent snapshots/resources
  or automatically send replacement traffic.
- Label changes, normal fixture state and TTL expiry do not erase valid history.
  New requests still require a live verified session.
- SQLmap remains one HTTP GET query input and minimal database/current-user
  metadata. Yakit replay remains public GET via real stdio MCP.
- Kali's installed nmap/nuclei/other binaries are catalog-only where no execution
  adapter exists. No arbitrary shell, generic scanner or automatic installation
  was introduced. WSL's missing Node/Yak dependencies are reported honestly.
- Native/WSL workspaces must not concurrently share SQLite. Localhost is never
  silently rewritten to a gateway, and target scope is not widened.
- Trusted local executables remain a prerequisite: fixed argv and scope checks
  are not an OS sandbox. Artifact text is untrusted and does not confer authority.

## Validation And Release

Run `npm.cmd run check`, `npm.cmd run test:python` and `npm.cmd run pack:check`.
The authoritative continuation logs and live WSL results are under
`.validation/resume-20261029-214119/`; `.validation/package-check.json` records
the verified archive and digest. Unit/integration regressions use mocks or new
local loopback fixtures, never historical targets. Package smoke sends no target
requests and does not launch or change the desktop host.

Kali live validation executes a trusted SQLmap version check and local sleeping
process fixtures only. It checks Unicode round trips, host abort/deadline and
guardian-local deadline, then verifies guardian/worker/engine/tool/grandchild
PID/start-time/process-group identities stop. It does not call version discovery
a vulnerability test. The skill validator also runs in the existing Kali Python
environment without installing a missing native dependency.

The retained release is `.validation/awa-ddd-0.6.0.tgz`. Install it only into the
chosen dsh profile and reload the plugin; source edits and packaging alone do not
update a running host. See [Windows/WSL](WINDOWS_WSL.md),
[host contract](HOST_CONTRACT.md), [internal contract](INTERNAL_CONTRACT.md) and
[SQL/MCP workflow](SQL_METADATA_AND_MCP.md) for exact usage and boundaries.
